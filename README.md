# mySocialWatcher
Dockerized pySocialWatcher and centralized data hub for easy deployment on across multiple virtual machines.  

#### Current features

1. portable Dockerized deployment of pySocialWatcher collectors
2. Centralized storage of raw pySocialWatcher data
3. PostgreSQL data hub to long-term data storage and sharing
4. Flask API for reading/writing data from/to database
5. Utilities for creating collection specs
6. cron scheduler  
7. session logging  
8. healthchecks.io notifications (email, sms, slack, etc) for server failures and/or python errors
